# exto

Type-safe SQL for [Bun](https://bun.sh): import `.sql` files into TypeScript,
typed from your migrations, with no database needed to type-check.

> [!WARNING]
> exto is being rebuilt around plain SQL and isn't usable yet. The query
> builder it used to be lives on the
> [`archive/query-builder`](https://github.com/rwillians/exto/tree/archive/query-builder)
> branch, and in releases up to 0.1.2.
